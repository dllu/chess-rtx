# Cburnett 45×45 chess pieces

The SVG files in this directory are adapted from Cburnett's “standard transparent” chess-piece
set on Wikimedia Commons:

- White: [king](https://commons.wikimedia.org/wiki/File:Chess_klt45.svg),
  [queen](https://commons.wikimedia.org/wiki/File:Chess_qlt45.svg),
  [rook](https://commons.wikimedia.org/wiki/File:Chess_rlt45.svg),
  [bishop](https://commons.wikimedia.org/wiki/File:Chess_blt45.svg),
  [knight](https://commons.wikimedia.org/wiki/File:Chess_nlt45.svg), and
  [pawn](https://commons.wikimedia.org/wiki/File:Chess_plt45.svg)
- Black: [king](https://commons.wikimedia.org/wiki/File:Chess_kdt45.svg),
  [queen](https://commons.wikimedia.org/wiki/File:Chess_qdt45.svg),
  [rook](https://commons.wikimedia.org/wiki/File:Chess_rdt45.svg),
  [bishop](https://commons.wikimedia.org/wiki/File:Chess_bdt45.svg),
  [knight](https://commons.wikimedia.org/wiki/File:Chess_ndt45.svg), and
  [pawn](https://commons.wikimedia.org/wiki/File:Chess_pdt45.svg)

The author offers each work under several alternative licenses. Chess RTX uses the BSD 3-Clause
option. See [LICENSE](LICENSE) for the complete notice and terms.

Changes made for Chess RTX: editor metadata and document declarations were removed, path data was
minified, and a uniform SVG wrapper and `viewBox` were added. The geometry and original piece
colors are preserved.
